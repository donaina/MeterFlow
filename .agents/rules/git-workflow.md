# Git & Pull Request Rules

- **NEVER push directly to `main`**.
- Always create a dedicated feature or bugfix branch (e.g., `feat/<feature-name>`, `fix/<bug-name>`).
- Push the branch to `origin <branch-name>`.
- Open a Pull Request via GitHub (`gh pr create` or GitHub web link).
- **Wait for the user's explicit review and approval** before merging any PR into `main`.
