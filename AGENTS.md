# MeterFlow Agent Guidelines

## Mandatory Git Workflow
1. **Never push directly to `main`**.
2. Always create a dedicated branch (e.g. `feat/...`, `fix/...`, `docs/...`).
3. Push changes to the feature branch on GitHub.
4. Raise a Pull Request (PR) for the changes using `gh pr create`.
5. Wait for user review and explicit approval before any merge to `main`.
